## ターミナル: 文字でパソコンに指示する

普段はマウスでフォルダを開いたりアプリを起動したりしています。ターミナルは、同じことを文字で指示するための画面です。Mac なら「ターミナル」アプリがはじめから入っています。

開くと、こんな行が表示されて入力を待っています。

```sh
yourname@MacBook ~ %
```

`%` の後ろにコマンドを打って Enter を押すと実行されます。まずは次の 3 つだけ覚えれば十分です。

| コマンド | 意味 | 例 |
|---|---|---|
| `pwd` | 今いるフォルダを表示する | `pwd` |
| `ls` | 今いるフォルダの中身を一覧する | `ls` |
| `cd` | 別のフォルダに移動する | `cd Documents` |

試しに打ってみましょう。

```sh
pwd
# /Users/yourname

ls
# Desktop  Documents  Downloads ...

cd Documents
pwd
# /Users/yourname/Documents
```

`#` から後ろは説明のためのメモで、打つ必要はありません。Finder でフォルダを開いていくのと同じことを、文字でやっているだけです。

## Claude Code: ターミナルで動く AI

Claude Code は、ターミナルの中で動く AI です。チャットのように話しかけると、フォルダの中のファイルを読んだり、コマンドを実行したり、ファイルを書き換えたりしてくれます。

ブラウザのチャットとの一番の違いは、あなたのパソコンのファイルを直接触れることです。そのため、ファイルを書き換える前やコマンドを実行する前には「実行していい？」と確認を求めてきます。何をしようとしているか読んでから許可してください。

## skill: Claude に渡す手順書

skill は、特定の作業のやり方を Claude に教えるための手順書です。リポジトリの `.claude/skills/` というフォルダに置いておくと、Claude Code がそれを読んで、その手順に沿って動きます。

このチュートリアル用の skill が、研究室サイトのリポジトリに入っています。この skill を読んだ Claude は、次のように動きます。

- 今どの章にいるかを覚えていて、次にやることを 1 つずつ示す
- 答えを全部書いてしまわず、あなたに手を動かさせる
- 章の終わりに「自分の言葉で説明してみて」と問いかける

## やってみよう: チュートリアルを始める

1. Claude Code が入っていなければ、ターミナルで次を実行してインストールします（[公式の手順](https://code.claude.com/docs/ja/quickstart)）。

   ```sh
   curl -fsSL https://claude.ai/install.sh | bash
   ```

2. 研究室サイトのリポジトリを手元に持ってきます。`git clone` の意味は次の章で学ぶので、今は写して実行するだけで大丈夫です。

   ```sh
   cd ~/Documents
   git clone https://github.com/sfc-icar/sfc-icar.github.io.git
   cd sfc-icar.github.io
   ```

   はじめて `git` を使う Mac では、開発ツールのインストールを求める画面が出ることがあります。その場合はインストールしてから、もう一度実行してください。

3. そのフォルダで Claude Code を起動します。

   ```sh
   claude
   ```

4. 起動したら、こう話しかけます。

   ```
   はじめよう
   ```

Claude が案内を始めたら準備完了です。途中でやめても、次に起動したときに「続き」と言えば、止まったところから再開できます。
