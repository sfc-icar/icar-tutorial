## ターミナル: 文字でパソコンに指示する

普段はマウスでフォルダを開いたりアプリを起動したりしています。ターミナルは、同じことを文字で指示するための画面です。Mac なら「ターミナル」アプリがはじめから入っています。

開くと、こんな行が表示されて入力を待っています。

```sh
yourname@MacBook ~ %
```

`%` の後ろにコマンドを打って Enter を押すと実行されます。まずは次の 3 つだけ覚えれば十分です。

| コマンド | 意味 | 例 |
|---|---|---|
| `pwd` | 今いるフォルダを表示する | `pwd` |
| `ls` | 今いるフォルダの中身を一覧する | `ls` |
| `cd` | 別のフォルダに移動する | `cd Documents` |

試しに打ってみましょう。

```sh
pwd
# /Users/yourname

ls
# Desktop  Documents  Downloads ...

cd Documents
pwd
# /Users/yourname/Documents
```

`#` から後ろは説明のためのメモで、打つ必要はありません。Finder でフォルダを開いていくのと同じことを、文字でやっているだけです。

## Claude Code: ターミナルで動く AI

Claude Code は、ターミナルの中で動く AI です。チャットのように話しかけると、フォルダの中のファイルを読んだり、コマンドを実行したり、ファイルを書き換えたりしてくれます。

ブラウザのチャットとの一番の違いは、あなたのパソコンのファイルを直接触れることです。そのため、ファイルを書き換える前やコマンドを実行する前には「実行していい？」と確認を求めてきます。何をしようとしているか読んでから許可してください。

## 案内役の Claude

このチュートリアルでは、Claude Code に案内役をしてもらいます。トップページにあるプロンプトを貼ると、Claude はこのサイトにある「案内役への指示書」を読んで、次のように動きます。

- 今どのレッスンにいるかを記録して、次にやることを 1 つずつ示す
- 答えを全部書いてしまわず、あなたに手を動かさせる
- レッスンの終わりに「自分の言葉で説明してみて」と問いかける

Claude に頼むことを文章で渡す、この「プロンプト」と「指示書」の考え方は、研究でも Claude を使うときにそのまま役立ちます。

## コマンドは自分で打つ

Claude はコマンドを示しますが、打つのはあなたです。打ち方は 2 通りあります。

- Claude Code の入力欄で、先頭に `!` を付けて打つ。たとえば `! git status` と送ると、その場で実行され、結果が Claude にも見える
- ターミナルのウィンドウをもう 1 つ開いて、そちらで打つ

はじめは `!` の方が楽です。結果を Claude がそのまま読んで、次の案内をしてくれます。

## やってみよう: チュートリアルを始める

1. Claude Code が入っていなければ、ターミナルで次を実行してインストールします（[公式の手順](https://code.claude.com/docs/ja/quickstart)）。

   ```sh
   curl -fsSL https://claude.ai/install.sh | bash
   ```

2. 作業用のフォルダに移動して、Claude Code を起動します。

   ```sh
   cd ~/Documents
   claude
   ```

3. [トップページの「はじめかた」](../../#start) にあるプロンプトをコピーして、Claude Code に貼り付けて送ります。

4. Claude の案内に沿って、研究室サイトのリポジトリを手元に持ってきます。`git clone` の意味は次の章で学ぶので、今は案内どおりに打つだけで大丈夫です。

   ```sh
   ! git clone https://github.com/sfc-icar/sfc-icar.github.io.git
   ```

   はじめて `git` を使う Mac では、開発ツールのインストールを求める画面が出ることがあります。その場合はインストールしてから、もう一度実行してください。

途中でやめても、次に起動したときに同じプロンプトを送れば、止まったところから再開できます。
