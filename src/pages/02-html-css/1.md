## ページはファイルでできている

ブラウザで URL を開くと、裏ではこんなことが起きています。

<figure>
  <img src="../../images/browser.svg" alt="サーバーが HTML、CSS、画像のファイルを送り、ブラウザがそれを組み立てて画面にする" />
  <figcaption>サーバーがファイルを送り、ブラウザがそれを組み立てて画面にする</figcaption>
</figure>

1. ブラウザが、URL の先にあるサーバーに「ページをください」と頼む
2. サーバーが、HTML ファイルを送り返す
3. ブラウザが HTML を読み、その中で指定された CSS や画像もサーバーに頼む
4. ブラウザが、それらを組み立てて画面に表示する

Web ページの正体は、ただのテキストファイルと画像ファイルです。研究室サイトの場合、サーバーは GitHub Pages で、ファイルは GitHub のリポジトリに置かれています。

## HTML は構造、CSS は見た目

ページを作るファイルには役割分担があります。

| ファイル | 役割 | たとえると |
|---|---|---|
| HTML | 何が書いてあるか（見出し、文章、画像、リンク） | 家の骨組みと部屋割り |
| CSS | どう見せるか（色、大きさ、配置） | 壁紙や家具の配置 |
| JavaScript | 動きをつける（クリックで開くなど） | 電気や水道の設備 |

このチュートリアルでは HTML と CSS を扱います。JavaScript は今回は使いません。

同じ HTML でも、CSS を変えるとまったく違う見た目になります。逆に、CSS だけでは中身は書けません。この分担を意識すると、どのファイルを直せばいいかが分かるようになります。

## やってみよう: ページの中をのぞく

ブラウザ（Chrome か Safari）で [今の研究室サイト](https://icar.sfc.wide.ad.jp/) を開いてください。

1. ページのソースを見る: `⌘ + ⌥ + U` を押します。ブラウザが受け取った HTML がそのまま表示されます。`村井純` を `⌘ + F` で探してみてください。

2. デベロッパーツールを開く: ページに戻り、`⌘ + ⌥ + I` を押します。Safari の場合は、先に「設定 → 詳細 → Web デベロッパ用の機能を表示」をオンにしてください。

3. 要素を選ぶ: デベロッパーツール左上の矢印のアイコンをクリックしてから、ページ上のメンバーの名前をクリックします。その名前に対応する HTML の行が光ります。

4. 書き換えてみる: 光った行の名前の部分をダブルクリックして、自分の名前に書き換えて Enter。画面の表示が変わります。

<aside class="note">

デベロッパーツールでの変更は、あなたのブラウザの画面だけに起きています。サーバーのファイルは変わらないので、再読み込みすると元に戻ります。安心していろいろ試してください。

</aside>
