## このチュートリアルでやること

iCAR のサイト（icar.sfc.wide.ad.jp）は、何年も前に1枚の HTML ファイルで作られたまま、メンバーも業績も古くなっています。これをみんなで作り直します。

作り直しながら、次の3つを順に身につけます。

1. git: 変更の履歴を残し、みんなで同じファイルを触るための道具
2. HTML と CSS: Web ページがどうできているか
3. フレームワーク: ページを部品に分けて、楽に保守するための仕組み

細かい書き方を覚える必要はありません。どこを変えると何が変わるのか、が分かればじゅうぶんです。書くのは Claude Code に手伝ってもらいます。

## 学ぶ: Claude Code と skill

Claude Code は、ターミナルで動く AI です。ファイルを読んだり、コマンドを実行したりしながら作業を手伝ってくれます。

skill は、Claude に渡す「仕事の手順書」です。このチュートリアル用の skill が研究室サイトのリポジトリに入っていて、Claude はそれを読んで案内役になります。

Claude は答えを全部書いてはくれません。次に何をするかを示して、手を動かすのはあなたです。

## やる

1. 研究室サイトのリポジトリを手元に持ってくる
2. そのフォルダで Claude Code を起動して「はじめよう」と言う
3. 今のサイトをブラウザで開いて、古いと思うところをメモする
