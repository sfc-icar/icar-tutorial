## 学ぶ: 変更の履歴を残す

（下書き）commit は「この時点の状態」を名前付きで保存すること。branch は本流を壊さずに試すための枝分かれ。push は手元の履歴を GitHub に送ること。

## やる

1. `git log` で、今のサイトが誰にいつ変えられてきたかを見る
2. 自分の branch を作る
3. 小さな変更を commit して push する

## できたら次へ

- [ ] commit とは何かを自分の言葉で説明できる
- [ ] GitHub 上に自分の branch が見える
