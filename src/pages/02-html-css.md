## 学ぶ: HTML は構造、CSS は見た目

（下書き）ブラウザは HTML を読んで「何がどこにあるか」を知り、CSS を読んで「どう見せるか」を決める。デベロッパーツールで、その両方をその場で覗ける。

## やる

1. デベロッパーツールで、今のサイトの色や余白を変えてみる
2. `index.html` に、自分をメンバーとして手で追加する

## 気づいてほしいこと

自分1人を足すだけで、何百行もの中から場所を探してコピーしたはずです。毎年これを全員分やるのは大変で、間違えやすい。次の章は、この面倒をどう解決するかの話です。
