# icar-tutorial

iCAR 研究室の新人チュートリアル。研究室サイトを作り直しながら、git・HTML/CSS・フレームワークを学ぶ。

公開先: https://icar.sfc.wide.ad.jp/icar-tutorial/

## 手元で見る

```sh
npm install
npm run dev
```

## ファイルの場所

- `src/chapters.ts`: 章の一覧（上部バーとトップページはここから作られる）
- `src/pages/*.md`: 各章の本文
- `src/layouts/`: ページの枠
- `src/styles/global.css`: 見た目
